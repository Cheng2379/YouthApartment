# 青年公寓App

## 简介
青年公寓是一款面向年轻人的租房应用，致力于提供便捷、高效的租房服务。该应用采用Kotlin语言开发，基于现代Android开发技术栈，为用户提供以下核心功能：
- 房源检索与筛选
- 租房预约
- 查看房源详细信息
- 租约管理

## 实现技术
### 架构设计
- 采用MVC架构，确保代码结构清晰、易于维护。

- 集成并自定义了多种工具与扩展函数，包括：
    - **RetrofitUtil**：封装后调用更加简洁高效。
    - **Logger**：自定义封装，可快速定位目标文件的日志行数。
    - **ExpandTool** 和 **DataUtil**：简化复杂逻辑，提高代码可读性。

### 异步处理
- 采用Kotlin协程进行异步处理，有效管理耗时任务，提升应用性能。

### UI设计
- 使用自定义View与动画，减少重复代码，增强可维护性。
- 实现自定义图片裁剪变换，提升用户体验。

### API支持
- 支持Android API版本26至35
